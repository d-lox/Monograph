# Monograph
Monograph 🖋️✨
A tactile, distraction-free retro typewriter app designed for short notes, essays, and deep writing.
Monograph brings the addictive, mechanical feel of a physical typewriter to your mobile device. Built for writers who love minimal design, sensory feedback, and zero clutter.
✨ Core Features
Bullet POS Receipt Roll Feed: A continuous vertical paper scroll that moves fluidly as you type and strike carriage returns.
Bullet Mechanical Sound & Haptic Engine: Crisp, zero-latency keystroke audio feedback paired with tactile vibrations for every letter.
Bullet Night Light Mode: An adjustable warm desk lamp spotlight illuminating your text for late-night writing sessions.
Bullet The Box (Archive): Fully offline local storage (localStorage) to save, manage, and revisit all your past paper rolls.
Bullet Custom Toolbar & Settings: Quick access drawers for machine styling, lighting controls, and note archiving.
🛠️ Tech Stack & Build
Bullet Frontend: Single-file high-performance HTML5, CSS3, and JavaScript architecture.
Bullet Wrapper: Capacitor Android wrapper configured for native mobile compilation via GitHub Actions.
Bullet Pipeline: Automated CI/CD workflow (build.yml) that compiles an installable Android .apk directly from repository pushes.
